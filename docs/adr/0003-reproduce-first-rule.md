# The experimental rule is "run the tests before and after the fix"

The skill's rule requires the agent to run the Task's pytest file before its first edit to the program and again after its last edit. The obvious alternative, "run the tests after fixing", was rejected because agents already do it almost every time, so both Conditions would sit at ceiling and RQ1 could not detect a difference. Agents often skip the before-edit run on a one-line bug, which leaves room for wording to matter. "I tested before and after" is also an easy claim to overstate, which gives RQ2 and RQ3 something to measure. Compliance is checked from the ordering of tool calls in the transcript. We chose one rule instead of combining it with a fix-log rule so that the L2 and L5 files can differ in wording only.
